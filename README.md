# E-Commerce Multi-Vendor

Template awal marketplace dengan 3 role:
- Customer
- Seller
- Admin

## Jalankan lokal
```bash
npm install
npm run dev
```

## Struktur halaman
- `/` Home
- `/login` Login
- `/customer` Customer Dashboard
- `/seller` Seller Dashboard
- `/admin` Admin Dashboard

## Tahap berikutnya
1. Supabase Auth
2. Database users/roles
3. Produk dan kategori
4. Keranjang
5. Checkout
6. Pesanan
7. Seller management
8. Admin management
9. Payment gateway
